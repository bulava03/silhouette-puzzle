# Legacy: Java Swing "Constructor"

The desktop version this project grew out of, kept unchanged. It is a Swing
window with 25 coloured rectangles (`JPanel`s) that can be dragged with the
mouse to build a picture. There is no rotation, no levels and no check that
the picture is complete; those are what the web version adds.

It is not part of the build. To run it, compile and start `Main` from `src/`
with any JDK.
